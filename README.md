# X Media Downloader

X(Twitter) 트윗의 이미지(원본), GIF(`.gif` 변환), 동영상(최고 화질 `.mp4`)을 원클릭으로 지정한 하위 폴더에 저장하는 Chrome/Edge 확장프로그램입니다.

## 주요 기능

- **이미지**: `name=orig` 원본 화질로 일괄 다운로드
- **GIF**: 브라우저 내에서 실제 `.gif` 파일로 변환 후 저장 (설정에서 `.mp4` 저장으로 전환 가능)
- **동영상**: 최고 비트레이트 `.mp4` 다운로드
- **폴더 프리셋**: 팝업에서 하위 폴더 프리셋을 등록해 두고, 트윗 버튼 호버/우클릭(또는 클릭 메뉴)으로 커서 이동 없이 바로 폴더를 골라 저장
- **파일명/폴더 분류**: `@아이디`별 하위 폴더 자동 생성 및 파일명 형식 선택 지원

## 설치 및 사용

1. `chrome://extensions` (Edge: `edge://extensions`) 접속 후 **개발자 모드** 활성화
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
3. 툴바 아이콘에서 폴더 프리셋과 버튼 동작 방식 설정 후 `x.com` 트윗 하단 다운로드 버튼 사용
