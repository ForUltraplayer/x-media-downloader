# X(Twitter) 원본 이미지 다운로더

`x.com` / `twitter.com` 트윗의 모든 이미지를 버튼 한 번으로 원본 화질로 지정한 폴더에 일괄 다운로드하는 Chrome/Edge 확장프로그램

## 주요 기능

- **원클릭 일괄 다운로드**: 이미지가 포함된 트윗 하단 액션 바에 다운로드 버튼(및 이미지 개수 표시)이 자동으로 추가됩니다. 클릭 한 번으로 해당 트윗의 모든 이미지(4장, 20장 등)를 한꺼번에 저장합니다.
- **원본 화질 자동 변환**: `pbs.twimg.com/media/...` URL을 `name=orig` 파라미터로 변환하여 원본 해상도 그대로 다운로드합니다.
- **저장 폴더 지정**: 확장프로그램 팝업에서 원하는 하위 폴더 경로(예: `X_Images`, `일러스트/트위터`)와 작성자(`@아이디`)별 폴더 분류, 파일명 형식을 설정할 수 있습니다.
  > **참고**: 브라우저 확장프로그램 보안 정책상, 지정한 폴더는 브라우저 기본 **다운로드** 폴더 내부의 하위 경로로 생성됩니다.

## 설치 방법 (개발자 모드)

1. Chrome 또는 Edge 주소창에 `chrome://extensions` (Edge는 `edge://extensions`)를 입력해 이동합니다.
2. 우측 상단의 **개발자 모드** 스위치를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭하고 이 프로젝트 폴더를 선택합니다.
4. 브라우저 툴바의 확장프로그램 아이콘을 클릭해 원하는 저장 폴더를 설정합니다.
5. `x.com`에서 이미지가 있는 트윗 하단의 다운로드 아이콘을 눌러 사용합니다.

## 파일 구성

- `manifest.json` — Manifest V3 설정 및 권한 정의
- `content.js` — `x.com` 트윗 감지, 원본 이미지 URL 추출, 다운로드 버튼 삽입
- `styles.css` — 트윗 액션 바 버튼 스타일
- `background.js` — `chrome.downloads` 기반 동시성 제한 일괄 다운로드 처리
- `popup.html` / `popup.css` / `popup.js` — 저장 폴더 및 파일명 설정 UI
- `icons/` — 확장프로그램 아이콘 (`16x16`, `48x48`, `128x128`)
