# X Media Downloader

`x.com` / `twitter.com` 트윗의 모든 이미지를 버튼 한 번으로 원본 화질로 지정한 폴더에 일괄 다운로드하는 Chrome/Edge 확장프로그램

## 주요 기능

- **이미지**: `name=orig` 원본 화질로 일괄 다운로드
- **GIF**: 브라우저 내에서 실제 `.gif` 파일로 변환 후 저장 (설정에서 `.mp4` 저장으로 전환 가능)
- **동영상**: 최고 비트레이트 `.mp4` 다운로드
- **폴더/파일명 설정**: 브라우저 기본 `다운로드` 폴더 내 하위 폴더 지정 및 `@아이디`별 폴더 분류 지원

## 설치 및 사용

1. `chrome://extensions` (Edge: `edge://extensions`) 접속 후 **개발자 모드** 활성화
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
3. 툴바 아이콘에서 저장 하위 폴더 설정 후 `x.com` 트윗 하단 다운로드 버튼 클릭
